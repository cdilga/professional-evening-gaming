Platform pattern

Not a monorepo prison. A shared control plane.

Every project lives under a small contract file, then chooses its own language, Dockerfile, CI path, and runtime. The root site only indexes those contracts and links to whatever each project becomes.

Project contract GitHub Actions GHCR image or static artifact Cloudflare tunnel or Pages

Operating rules

  • Public shell: keep the homepage and `/projects/` fast, static, and easy to mess with.
  • Private core: Postgres never goes public; the API sits in front with CORS and health checks.
  • Schema lanes: each serious project can claim its own schema and migrations.
  • Repeatable deploys: GitHub Actions build, push, tunnel over SSH, migrate, and restart.
