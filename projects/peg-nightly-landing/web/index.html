Independent static lane

PEG Nightly Landing

This is a deliberately separate static project. It proves PEG can spin up a standalone microsite without touching the main GitHub Pages shell or inheriting any backend stack it does not need.

Use it for

event teasers, temporary campaigns, sign-up pages, or one-off experiments with zero database baggage.

Deploy path

GitHub Actions builds a small nginx image, publishes to GHCR, then rolls it out to the private host.

Why it matters

PEG projects do not need to be trapped inside one root build. Static can stay static.
