# Barrels-as-a-Service

Funny barrel stuff for PEG.

## What it is

A deliberately unserious static project page that came out of Discord banter and got folded into the PEG project rail properly.

## What it does

- shows fake barrel throughput metrics
- renders a sketchy canvas chart
- refreshes a stream of made-up ops events
- gives the lads a clickable joke feature instead of just chat dribble
