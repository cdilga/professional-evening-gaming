Project spotlight

Astacus Bot

The first proper service lane for PEG: Discord-triggered work, a FastAPI surface, private Postgres, and migrations on every deploy so the bot can keep durable state without exposing the database.

Back to all projects View repo

Current shape

  • API: FastAPI container with CORS for the static site.
  • Data: PostgreSQL 16 with an `astacus_bot` schema.
  • Deploy: GHCR image, cloudflared SSH, compose rollout, then migrations.
  • Extensibility: add more schemas as new PEG projects need durable state.

What it unlocks

  • Discord bot commands can persist notes, jobs, or project state.
  • Static Pages frontends can call a stable API host with CORS enabled.
  • Each new service-backed project can claim its own schema and endpoints.

Source layout

  • `projects/astacus-bot/peg-project.json`
  • `projects/astacus-bot/api/`
  • `projects/astacus-bot/infra/docker-compose.yml`
  • `projects/astacus-bot/infra/scripts/deploy.sh`
